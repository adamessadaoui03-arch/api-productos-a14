# API de productos

API REST sencilla que devuelve una lista de productos almacenados en memoria.

## Tecnología

- Node.js
- Express

## Endpoints

| Método | Ruta | Descripción |
|--------|------|-------------|
| GET | `/api/productos` | Lista todos los productos |
| GET | `/api/productos/{id}` | Devuelve un producto por su id |
